# STアプリ

STで使用する注意障害訓練とCAT-R入力をまとめた静的Webアプリです。

## 公開版に含めるもの

- STアプリ本体
- 注意障害訓練
- CAT-R入力
- ホーム画面追加用のマニフェストとアイコン
- オフライン使用のためのService Worker

## 公開版に含めないもの

- ローカルHTTPS配布用の証明書
- 秘密鍵
- Mac内の個人フォルダ名を含む手順
- 院内IPアドレスやMac名
- ローカル配布用ツール

## 情報管理

このアプリは静的なHTML/CSS/JavaScriptとして動作します。利用者IDや結果履歴は、使用している端末のブラウザ内に保存されます。GitHub Pagesへ自動送信する処理は入れていません。

運用時は、氏名、電カルID、生年月日、カルテ番号など、個人が特定される情報を利用者IDに入力しないでください。

## オフライン使用

初回導入時または更新時はオンライン接続が必要です。ホーム画面に追加し、必要ファイルの保存が完了した後は、オフラインでも起動・使用できます。
